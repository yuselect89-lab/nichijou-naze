# 女性キャラクターの共通演出基準
2026-10-22 ユーザー承認方針。適用：日常のなぜ？の企画・映像設計・素材制作・編集・QC。

## 目的
「親しみやすい女の子が身近な疑問を解説してくれる」をブランドの軸にする。小さい全身キャラが隅で動くだけのマスコット配置を標準にしない。かわいさは、説明に結び付いた表情と仕草から伝える。支持向上は仮説であり実績と断定しない。

## 設計
1. 各カットへ役割を明記：question / reaction / reveal_intro / process_intro / payoff / focus_only。
2. question・reaction・payoffは高解像度原本の上半身を大きく表示。顔の初期目安は1080幅で約180〜300px、360幅で60〜100px。全身の高さだけで合否を決めない。
3. 科学現象の核心はfocus_onlyとして非表示にしてよい。キャラを読めない大きさに縮めることを標準の回避策にしない。
4. 指差しは説明対象と一致させる。字幕・矢印終点・液面・気泡・比較対象の中心を隠さない。役割を終えたら自然に退く。
5. 無目的な歩き回り・常時上下動を避ける。フェード・表情の切替・短い頷きは説明の節目に限定。口パクは完成・承認済み機能だけを使う。
6. 本編の尺・声・台本を維持する依頼では、キャラ変更のために台詞を増減したり音声を高速化しない。

## 素材・編集
- 登録台帳で共通素材ID・版・実体・依存・権利・プレビュー・レンダリングを確認し、再利用／改修／新規を判断する。新作はEPで検品してから汎用分を版付きで登録する。
- 背景・科学モデル・説明ラベル・キャラのレイヤーを分離する。合成済み映像にキャラを重ねて二重表示しない。既存の340px全身設定は互換性用の値であり、本番配置の推奨値と扱わない。
- 高解像度原本から上半身をクロップする。既存の小さな動画レイヤーをそのまま拡大してぼかさない。
- 正式黄色帯PNG、全編の単一経過時間バー、読点除去・句点保持の字幕を維持する。

## QC受入条件
- 360px幅の実際の動画を確認し、思案・驚き・笑顔の違いが読める。
- 「この子が案内している」と感じる導入・反応・締めがある。
- キャラの登場前後を連続確認し、核心の図解・ラベル・字幕・顔・Shorts UIが干渉しない。
- 指差しの方向と対象が合う。図解優先の場面では視線が図解へ戻る。
- 各カットの役割・登場時刻・クロップ・大きさ・保護対象を編集データへ保存する。
- G2指示とG3プロンプトに上記を入れる。既存G3 PASS後に配置を変えた版は変更部分を再QCする。過去版のPASSを自動継承しない。
