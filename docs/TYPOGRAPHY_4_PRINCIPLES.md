# Typography 4 Principles｜今後の動画・図解制作の共通基準

適用開始：2026-10-30／対象：このリポジトリでこれから新規に設計・制作・改訂するカット、SVG/PNG素材、モーション、図解、表示文字。**既存の承認済み動画・台本LOCK・素材・字幕・シリーズブランドには遡及しない。**

> 「日常のなぜ？」専用運用：新規エピソードの図解・テロップ・タイトルに適用する。**承認済み黄色帯は一切触らない**。ナレーション同期字幕の焼き込み、読点・句点処理、全編進行バー、中心基準・YouTube UI安全域・360pxチェックは既存の正本を優先。冒頭は実物・動作主体で、文字強調だけの静止紙芝居化は禁止。素材ライブラリの版・再利用・QCも従来どおり。

## 目的と優先順位
ユーザー指定の4原則を、感覚的な装飾指示ではなく **G2設計→素材発注→実物G2/G3 QC** の判断基準にする。主題が伝わり、動画として魅力的であることが目的。文字を飾ることが目的ではない。

1. **大小の強弱**：カットの「最初に見せる情報（主役）」と「読ませる情報（補助）」を先に決め、サイズ差を作る。意味のある主役を大きくするのであって、台本の全文や長文の問いをただ拡大しない。既存のサイズ規格・安全域を優先し、数値を独断で改定しない。
2. **太さの強弱**：強調語に実在する太字ウェイト／太い書体を選び、補足を細いウェイトにする。機械的な擬似ボールドを第一選択としない。字形（特に複雑な漢字、濁点、細線）をレンダリングして潰れを検査。主役・補助のウェイト指定を素材／カット仕様に記録する。
3. **明暗の強弱**：主役は背景から分離し、従要素を落として視線を誘導。暗いだけ・派手なグローだけにしない。最も暗い部分と明るい部分で実際の絵を焼いて確認し、色覚・グレースケールでも主従が識別できることを確かめる。シリーズで禁止／承認待ちの色は使わない。
4. **明朝・ゴシックの使い分け**：明朝（serif/mincho）は大型の演出的な字・編集的な見出しの候補、ゴシック（sans/gothic）は短時間で読む説明・小ラベルの候補。ただし強制しない。字形の正確さ、読める速度、既存フォント指定、演出意図で選択し、「なぜその書体か」を一行で説明する。端末でフォントが代替されていないか、必要字形と商用利用条件を検査。

## 既存工程で必ず残す証跡（新しい承認Gateは増やさない）
- **G2映像設計／カット割**：文字が出る各カットに `primary_text`（第一視認情報）、`secondary_text`、`size_hierarchy`、`weight_strategy`、`luminance_strategy`、`typeface_reason` を記述する（既存の文書・visual beatsに項目として追記。既存JSONスキーマに未定義キーを無断追加しない）。文字を使わないカットは `N/A: visual-first` と記録する。
- **Codex / Claude Design / SVG発注**：G2の4項目と参照デザインを発注に転記。書体名／利用ウェイト／ファイル実在／フォールバック／字形／レイヤー分離／ライセンス確認を明記。3Dの見た目をSVG平面代替して完成扱いにしない。
- **G2実物確認**：代表静止画に加え、動きが重要なら実再生試作を見て、大きさ・太さ・明暗・書体の意図が成立するかチェック。参考画像を貼っただけ、またはCSS設計値だけではPASSにしない。
- **G3/技術QC**：原寸とスマホ縮小表示を検品。可読性・階調・画面UI競合・字形欠け・フォント置換・タイミングを実際の動画フレームで確認。未検証なら未検証と明記してHOLD。既存G2/G3の判定に組み込み、別の承認待ちをユーザーに増やさない。

### G2/G3 の不合格例
- 重要語も補足も全て同サイズ・同ウェイト・同明度で平坦
- コントラスト不足、または暗すぎて対象が分からない
- 文字の潰れ、フォント置換による意図しない印象変化
- 構図に理由がない文字カードの連続、見本の質感と実納品の乖離
- 小さいスマホ表示で読めない／字幕・UIと重なる
- 未承認の装飾で意味や既存制作ロックを変更

## 制作ロックとの関係
この規則は **設計・QCの補強** のみ。承認済みブランド帯、音声、字幕形式、原稿、演出LOCK、素材原本、権利制約を改定しない。適用できない場合は理由と代替表現を既存のG2/QC記録に残す。無断で素材の差替え・画質ダウン・配色変更・BGM追加をしない。

## 具体的な最小記載例
- 主役：猩／涅 → 大。補助：Aka／Kuro → 相対的に小（技名を明かすタイミングは脚本LOCK準拠）。
- 太さ：主役の漢字は該当字形を持つ正規の太字書体を選定し、疑似ボールド禁止。
- 明暗：主役漢字を背景より明るく、背景の注記は抑える。全文を暗くしない。
- 書体：漢字主役は明朝系の存在感を候補、短い英語ラベルはサンセリフを候補。既存FONT LOCKが優先。
