# Work制作指示書｜日常のなぜ？ コンビニ入口の身長目盛り｜v2 A素材使用

## 目的と着手範囲

C01〜C07の完成映像素材を使い、ナレーション・字幕・正式黄色帯・単一の全編進行バーを備えた本編を制作する。設計書や無音の素材連結だけで終了せず、まず**音声付きラフMP4の実ファイル**を作り、G3に提出できる状態まで進める。

素材は用意済み。全7本の1080×1920 / 30fps / H.264 yuv420p / 無音、計1020フレーム・34秒を実測・全デコード確認済み。ただし**外部G2再審査は未実施、台本V1.1も未最終LOCK**。素材セルフQCをG2 PASSへ読み替えない。

既存指定は「G2 PASS後にWorkの本編編集」。まず下記のG2確認を行い、通過後に音声付きラフへ進む。今の依頼をG2の自動免除と解釈しない。G2結果待ちでも、素材取得・照合・プロジェクト準備・音声設定確認は進める。

## 2. G2から本編編集への移行

v2 Aの同じ実ファイルに対する外部G2結果が既に提供されているか確認する。実在するPASSがあれば、対象ファイル・判定日・結果を記録し、重複審査せず次へ進む。

まだ結果がなければ、上記実動画と `GEMINI_G2_REQC_HANDOFF_v2.md` を使い再QCする。特にC03の歩容・接地・写真との融合、C05/C06の回想の伝達、C07の残像を確認対象とする。審査手段が利用できない場合は依頼文と対象動画を揃え、「外部G2結果待ち」と明示する。勝手に有料APIを呼び出したり、セルフQCを外部PASSとして代用しない。

MINOR/MAJOR FIXが出たら、対象Cut・時刻・指摘・必要な素材修正を具体化する。旧人物へ戻したり、静止画/字幕で問題を隠さない。素材修正が必要な箇所はCodexへ返す。Aは素材制作上の採用案で、Bは未実施。

G2 PASS後、下記3〜8を実行する。台本はV1.1原文のまま検証用ナレーションを作れるが、最終SCRIPT LOCKと名付けない。本文変更が必要になった場合は独断変更せず差分と理由を示す。

## 4. ナレーション原文（V1.1・変更しない）

```text
コンビニの入口。この色付きの目盛り、何のため？

実は、強盗などの事件が起きたとき、逃げる犯人の身長を見積もるための防犯メジャーなんです。

でも、なぜ色まで分かれているのでしょう？

とっさの場面で数字は覚えられなくても、

「頭が赤い帯のあたりだった」なら、思い出しやすい。

あの小さな目盛りには、人の記憶を助ける工夫まで隠れているんです。
```

既存EPの承認済み声・話し方の設定があるか実物から確認し、同じ設定を再利用する。確認できない設定を承認済みと称しない。内部で利用可能な音声で検証用仮VOを作る場合は、仮音声であることを明記する。外部有料AI生成・外部API・クレジットを無断使用しない。

ナレーションは**全編一体の音声ファイル**として生成・管理する。Cutごとに別の声/速度/音量の7本へ分割しない。生成結果を実際に再生し、誤読・脱字・不自然な間・語尾切れを確認する。34秒に合わせるための無理な早口、音声の早回し、台本の短縮は禁止。

原文は身長の「目安」と色が記憶の手掛かりになる例示。正確な犯人身長の測定、必ず覚えられる効能、特定メーカー実製品の忠実再現を断定する語句を追加しない。人物は一般歩行者で、犯罪行為や追跡シーンは追加しない。

## 5. 実VOに合わせて編集する

音声の実測後にCut境界と字幕タイムコードを決める。文字数から算出した時刻を実測/完成字幕と呼ばない。

- C01の問いを入口と色帯の発見へ合わせる。
- 用途説明をC02→C03へ連続させ、「身長を見積もる」の説明が敷居通過の見せ場と対応するようにする。
- 色分けへの問いをC04、数字が曖昧になる部分をC05、「頭が赤い帯のあたりだった」をC06、最後の再認識をC07へ合わせる。
- C05→C06は一続きの回想。別画像への切替や不必要なフェードで関係を切らない。
- C07の残像が消えてからキャラが締める順序を保つ。

VOが仮尺に収まらない場合、音声を先に保護し、対象Cutだけの尺・保持・演出タイミングを編集データで調整する。C03の歩行を無断ループ/逆再生/大幅スローして埋めない。C01の発見、C03の同面の瞬間、C05/C06の連続、C07の残像→締めを壊さない。必要なら同梱ソースから該当素材を再出力し、変更Cutを再QCする。最終Manifestには実際の境界・尺・素材版を残す。

## 6. 本編レイヤーを一度だけ合成する

### 正式黄色帯

`production-lock.json` と `public/series/approved/opening_banner.png` を使う。PNGのSHA256は `e6b63c322c996f543930a027db8981c2388e88441656655822c34bb4e2e2fd37`。旧 `public/series/v1/opening_banner.png` は使わない。

[承認PNGの取得先](https://github.com/yuselect89-lab/nichijou-naze/raw/01730cb8b6be04f6ee9cf2f7e0d1f6134f322ead/public/series/approved/opening_banner.png)

制作前に専用リポジトリで `node tools/verify-production.mjs` を実行し、原本とロックを照合する。失敗したら代替帯を作らない。配置は正本に従い、原画像の文字・色・形・比率を変えない。

冒頭C01の全尺に表示する。各Cutへ繰り返し焼いたり、素材内にあるものとして省略したりしない。顔・問い・色帯を隠さないことを合成後の実フレームで確認する。

### 進行バー

本編全体を通る一本。全体の実尺で0→100%。Cut境界でリセットせず、秒数・カウントダウンを追加しない。

### 字幕

採用した**実VO**に同期。表示直前に読点「、」だけを全件除去し、句点「。」と意味を保つ。JavaScriptなら `text.replace(/、/g, '')`、Pythonなら `text.replace('、', '')`。この処理のために台本や音声を変えない。

既存の日本語フォント・字幕スタイルを再利用する。顔、指先、赤帯、破線、残像、Shorts UIと競合しない。360px幅で読める行分けと文字量にし、長文を巨大な文字で画面全面へ敷かない。

### 音・CTA

BGM/SEは追加指示がないため入れない。VOの音量差とクリッピングをなくし、既存の承認済み音量基準があれば合わせる。

固定CTAの確定原文はこのパックでは未確認。既存の承認済み正本から確認し、勝手に作らない。未特定ならCTAなしのラフを先に作り、CTA未確認を明記する。確認不能を理由に素材取込やラフ全体を止めないが、CTA確認済みの最終版と称さない。

## 7. G3用の検品

実際の音声付きラフを1080pxと360pxで再生し、次を確認する。実行できていない検査はUNVERIFIEDと記録する。

- 冒頭4秒で入口→色帯の発見が映像でも分かる。正式帯が正しく一度だけ表示される。
- 同じ入口・同じ人物でつながり、旧v1人物が混じっていない。
- C03の接地・歩行・写真との融合が不自然でない。別距離を比べる横線や自動精密測定のような追加UIがない。
- C05/C06が現物の数字の消滅ではなく回想と分かり、頭頂と赤帯の関係が伝わる。
- C07の残像が通常人物と区別でき、出現→消失→キャラの締めが見える。
- VOの誤読/語尾切れがなく、字幕が実音声と同期。読点ゼロ・句点保持。
- 顔・字幕・正式帯・色帯・Shorts UIが干渉せず、進行バーは一本で全尺を通る。

G3指摘を修正し、修正したCut/音声/字幕/レイアウトを再確認する。旧版のPASSを変更版へ自動継承しない。外部審査・ユーザー承認の実在しない最終LOCK/PASS/公開済みを宣言しない。
