# NNZ_CHAR_FEMALE_01 — v02_highres

既存の女性解説キャラクターを参照して高精細に描き起こし、動画用に透過・余白・全身サイズを整えた5ポーズです。茶系のお団子ヘア、クリーム色パーカー、紺色パンツ、茶色の目、デフォルメ頭身を維持しています。

すべてRGBAの背景透過PNG。全身の描画高は約2160px、頭と靴の外側に約72pxの余白を揃えています。サムネイルは `thumbs/` の256×384px。5ポーズ一覧は `preview_v02_highres.jpg`。

## 解像度と制作方法

旧試作の253px高の切り出しを拡大したものではありません。既存資料シートと試作PNGを参照して、通常立ちを共通デザインの基準に高精細な描き起こしを行いました。生成元の画像サイズは通常1024×1536px、thinkは887×1774pxです。その新しい描き起こし画像の透過端を整理し、全身の高さと余白を揃えて1536×2304pxへ書き出しています。**ネイティブ2304pxで生成したと偽るものではありません。** 元の生成画像、切り出し範囲、技術的な倍率は `sources/v02_highres/` と `manifest.json` に記録しています。

輪郭外の極小alphaを除去し、生成器のほぼ不透明な画素を不透明へ正規化、透明画素下のRGBも整理しています。線や表情を単純なぼかしで作った素材ではありません。新規生成した描き起こしの線・陰影を使用しています。

## 向きと表情

指差しの右・左は **画面を見る人から見た方向** です。旧試作のpoint_leftは実際には右へ指していましたが、新版は左へ指す絵として制作しました。旧ファイルは変更していません。

通常立ちと話すは同じ正面寄りの顔・服・靴を基準に、腕のジェスチャーを分けています。thinkは少し首を傾けて考える表情、指差しは各方向への軽い斜め視点です。完全な3Dリグ／同じ顔画素の差分ではないため、角度・表情に伴う軽微な描画差は残ります。大きなデザイン変更や別衣装は行っていません。

talkは静止した説明ポーズであり、口パク動画や口形差分ではありません。

## 共通テンプレから呼ぶ

```json
{
  "characterVersion": "v02_highres",
  "characterPose": "point_right"
}
```

既存の `characterImage` を残すとその明示パスが優先されるため、バージョンとポーズから選ぶ場合は `characterImage` を外してください。新しい `tools/new-scene.mjs` は優先5ポーズにこの版を設定します。旧EP・既存examplesの設定は自動で書き換えません。surprise/happy/troubledは旧試作のままで、v02_highresには含めていません。

ランタイム画像は `public/common_assets/nichijou_naze/characters/female_v01/` に同一ファイルを同期しています。正本はこの `common_assets/` ディレクトリ。IDは不変、版はv02_highresです。

## 検証と使用範囲

`validation/highres/` に1080×1920／30fpsの確認シーン、中央の大表示5ポーズ、左右寄せ、矢印・比較・拡大との併用、字幕と帯を含むスクリーンショットと動画があります。大表示は画像高1220pxで確認します。素材の元描画に対して十分な解像度を保つため、一般的な縦動画では全身の表示高1200px前後以下を推奨します。納品PNGのピクセル数を超える極端な拡大を前提にはしていません。

## 保存・更新

旧253px高の短いファイル名PNGと原本vendorはそのまま保持しています。今後の別版は新しい版のサブフォルダとmanifestスナップショットを用意し、この5ファイルを上書きしないでください。表情差分はキャラID・ポーズ・表情名・版を記録して追加できます。
