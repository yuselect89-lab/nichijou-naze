## 3. CUTごとの編集

### C01：実写風の操作→点滅

新入力d670a464を使用した合成版。手の接触とレバー全体の持上げを見せ、ローカル1.90秒/57fから右矢印点滅。既にmediaへ表示補正済み。`layers/C01_DISPLAY_CORRECTION_ALPHA.mov` は再合成時だけ使用。

レバーは持上げ後に少し戻る。上げ位置での完全なラッチ保持や特定車種の電装実証として説明しない。小さい画面変動もある。これを最終QCで実画確認し、無条件の合格として先へ送らない。入力は720×1280/24fpsで、1080p30納品は拡大・フレーム複製。ネイティブ1080映像とは呼ばない。

正式帯をC01全体に一度配置。配置はproduction-lock.jsonに従い、透明余白を含む原本の縦横比を維持。操作/表示/顔/字幕/Shorts UIとの干渉を実フレームで検査する。C01にキャラを足さない。

### C02：キャラ→リレー内部

指差しポーズはNNZ_CHAR_FEMALE_01 v02_highres。mediaに合成済み。キャラ退場と内部への拡大を維持し、別の生成機械画像へ切替えない。

外装は無銘の模式外装で、特定の実在リレーの外観照合は未了。要求される実物外観との一致を確認できない場合、その点をG3の保留/修正として報告。未照合の模式外装を「実物撮影」として説明しない。

### C03/C04：同一モデルの比較

共通モデル/時刻制御はsource/render.py。周期制御→コイル励磁→可動鉄片/接点→灯の関係を保持。接点と灯の同期を崩す区間伸縮、別々のモデルへの差替え、架空の電流線、直接コンデンサ放電、激しい火花は追加しない。

C03/C04の仮境界を動かす場合、共通時計の連続性も確認する。機構の速度を勝手に変えず、必要なら共通ソースから該当区間を再レンダリングし局所修正する。C04へスピーカー/電子音生成器を先出ししない。

mediaには説明ラベルが焼かれていない。必要に応じ `layers/C03_labels.png` と `C04_labels.png` を対応するCUTへ一度だけ配置。これらは本字幕ではない。配置変更が必要なら機構・字幕・顔を隠さないことを360pxで確認。

### C05：運転手への通知

車内背景＋承認済みthink＋控えめな音波をmediaへ合成済み。耳に手を当てる新ポーズは作っていない。既存の自然な思案ポーズとして扱う。表示は元背景の点滅を測定して補強済み。

合成を調整する場合のみ `layers/C05_background_1080.mp4` と `C05_FOREGROUND_ALPHA.mov` を使用。mediaを下に敷いてさらに同じ前景を重ねない。キャラを説明の主役とし、運転手/レバー/長文を追加して画面を混雑させない。

### C06：昔の実作動音と今の再現音

上段のリレーはC03のモデル/関数を再利用。下段は電子制御による音信号とスピーカー方式の一例。全車に共通する仕組みとして描かない。

`layers/C06_labels.png` を必ず正しく使う。「昔」と「今（一部の車）」を保持する。PNGの上側y0–899を先に、下側y900–1919を現代側の登場以降に合成する。下段の現在の登場はローカル約0.62秒、強調は約1.20秒だが暫定。VOの実際の「わざわざ」に合わせて下段登場/強調cueを調整する。必要ならsource/render.pyのC06だけを局所再レンダリングする。C03/C04を無断で再制作しない。

ラストの「電子音で再現しているんです」に合わせて比較を完成し、終盤に理解する保持時間を残す。早い段階でスピーカーを見せない。スピーカーの振動は30fpsで読める時間拡大の模式演出で、実際の音響周波数を撮影再現したものではない。SEは加えない。

## 4. 字幕・ブランド・仕上げ

- 台本/VOの文言を変更しない。音声から字幕を作る場合は発話と照合する。表示直前に読点「、」のみ除去し、句点「。」を保持する。正式な台本が未取得ならその旨を記録し、推定全文を承認済み台本と呼ばない。
- 正式帯・本字幕・全編の単一進行バーは本編側で各1回合成。CUTごとに進行バーを0へリセットしない。
- キャラ・機構・表示・顔・Shorts UI・字幕の安全域は実動画360px幅で検査する。テンプレ初期座標を合格根拠にしない。
- 有料生成・新たな外部送信・投稿・公開を行わない。今回のGitHub素材納品の依頼を動画公開の許可に拡張しない。

## 5. Workの納品とG3

1. 正式音声付きラフMP4（1080×1920/30fps）と360px版を実書出し。
2. 編集プロジェクト、字幕データ、CUT/cue表、使用素材manifestを納品。
3. 実再生して、C01操作/点滅、C03接点/灯の完全同期、C03→04位置、C05顔と背景の一体感、C06の音生成の発見と保持を確認。360px通常再生、音声あり/なし、1080実フレームを検査。
4. G3結果には確認済み/不合格/未確認を分ける。C01ラッチ、C02実在外装、生成素材の利用条件は確認できた範囲のみ記録。古いG2 MINOR FIXの存在を現在の実画G3 PASSへ読み替えない。
5. 不合格なら時刻と問題を特定し、必要箇所だけ修正。台本/VO/正式帯/承認キャラや制作方式を無断で変更しない。修正後はその箇所を再検査。未了の状態を公開可能版として引き渡さない。
