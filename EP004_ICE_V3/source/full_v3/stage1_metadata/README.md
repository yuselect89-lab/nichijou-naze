## Cut09：使うレイヤーを選ぶ

### すぐ確認する場合

`animation.mp4`をそのまま使用します。キャラ・図解ラベル・矢印を含みますが、ナレーション字幕やシリーズ共通演出は含みません。

### Work側で配置を調整する場合

1. `base_animation.mp4`を背景に置く（3Dの部屋・製氷缶・氷・水・吸水管・排出の動き）。
2. 必要に応じて`character_overlay.webm`を重ねる。キャラだけの透過動画です。
3. 必要に応じて`labels_overlay.webm`を重ねる。名称ラベルと流れの矢印だけの透過動画です。

合成済み`animation.mp4`へさらに同じ透過動画を重ねないでください。アルファWebMに対応しない編集環境では、`character_point_right.png`と`character_motion.json`、編集可能ソースを使用してください。VP9の標準デコーダによっては透過を無視するため、アルファ対応の読み込みを確認します。

`background.png`は部屋だけ、`model.png`は代表時点85fの立体モデルだけを透過で出した静止素材です。**この2枚だけでは排水アニメーションを再現しません。** 水・氷・金属・管・排出先はソース内の独立グループとして編集でき、遮蔽関係を維持するため基本の動きは3Dでまとめてレンダーしています。

### 排水モデル

- 初めから前面・背面の一部が省略された説明用断面です。時間の途中で固体を削る動きはありません。
- 外側の氷は一体の固定形状。中央は液体として扱い、水面が連続して低下します。
- 吸水口が下へ入ってから排水開始。吸い上げる向きと、外へ下がる向きの流れを表示します。このカットには送気はありません。
- 中央から減る液体体積と排出先の増加を同じ値で制御しています。受け容器には奥行きがあり、容量を超えません。
- 管内に一時保持される少量や流体抵抗を省略した模式モデルです。実流体シミュレーションや工場の測定再現ではありません。
- 液体の青は見分けるための着色表現。氷の中央が青いという科学的主張ではありません。
- 終了時には中心の空洞と薄い残液が残ります。その場で完成した透明の塊にしません。Cut10は後工程を経た別時点としてつないでください。

## 再出力

既存プロジェクトを変更せず、新版フォルダとローカルに同梱したThree.js0.180.0で構成しています。リポジトリのルートから実行します。

```sh
npm ci --cache /tmp/nnz-v3-npm-cache
npx remotion studio EP004_ICE_V3/source/index.jsx
node EP004_ICE_V3/source/render.mjs
node --test EP004_ICE_V3/source/physics.test.mjs
```

Chromiumは`/usr/bin/chromium`、GPUのない環境では`gl:swangle`を使用。Blender/Cyclesの初回試作は表面ノイズと描画コストのため不採用とし、納品動画はThree.jsのPBRモデルです。Three.jsのMITライセンスを`licenses/`に同梱しています。既存依存宣言・node_modulesは変更していません。

時間・体積・残液は`source/physics.mjs`、立体形状・カメラ・材質・照明は`source/scene3d.mjs`、ラベルとキャラ・レイヤーは`source/index.jsx`で編集できます。カメラや形状を変えた場合はラベルのアンカー位置も合わせて再QCしてください。

キャラとラベルだけ修正した場合は`node EP004_ICE_V3/source/render.mjs --overlays-only`で3D再描画を省略できます。`model.png`の反射・屈折は書き出し時の環境を含むため、異なる背景へ光学的に正確に合成したい場合は3Dを再レンダリングしてください。
