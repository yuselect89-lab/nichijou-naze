## 0. 発見と視覚的な目標
- **問い**：「カチッ」と止まる電気ケトルは、どうやって沸騰を知る？
- **知る前→知った後**：お湯に接する温度センサーが直接水温を測るイメージ → **発生した蒸気が通路を移動し、熱でバイメタルが変形して電源が切れる**。
- **中心に見せる映像**：実際の沸騰とスイッチOFF → ケトル内部の蒸気の道筋 → 部品が変形してスイッチが跳ねる → 同じ実物に戻って「なるほど」。
- 最も重要なのは、見本の「実物が本物らしく見える画」と「奥行きがあり実際に動く内部構造」の両立。**意味不明の抽象CG・小さな玩具模型・黄色い点が流れるだけの安い図解で代用不可**。

## 2. 技術的な制約：模式図の物理を勝手に改変しない
一般的な蒸気検知式・バイメタル作動式ケトルを**代表例の模式モデル**として描く。機種ごとに蒸気通路・スイッチ位置・接点構造が異なりうるので、特定製品を実測した精密なカットアウェイと偽らない。

パーツIDを固定：
- `KETTLE_BODY`：同じケトルの外装／蓋／水面／注ぎ口／ハンドル。
- `BOIL_ZONE`：水面で泡が発生し、上の空間に蒸気が生じる領域。
- `STEAM_INLET`：湯面上の蒸気が入る取入口（底部や水中から突然蒸気が湧く誤描写は禁止）。
- `STEAM_CHANNEL`：内側上部からハンドル側などを経てスイッチ部へ通じる蒸気経路。代表模型では形状を固定。
- `BIMETAL`：スイッチ部で蒸気の**熱によって**変形／跳躍動作する金属部品。
- `ACTUATOR`：バイメタルの動きを受ける機械連結／スイッチ機構。
- `CONTACTS`：通電時は閉、停止時は開。**接点が開いて通電が止まる**因果を示す。
- `HEATER`：底面の発熱部。通電ON→OFFに伴って加熱停止。スイッチOFFと同時に水が突然冷える表現は禁止。

**正しい動作順：** 水が沸騰 → 水面上に蒸気 → 蒸気が通路へ → 蒸気でバイメタルが加熱・変形 → 連動機構がスイッチ接点を開く → 発熱停止。
- 蒸気が電気接点へ直接大量に流れ込む／水が電気部品へ接触する／蒸気圧だけでレバーを吹き飛ばす、という描写は禁止。
- 「蒸気＝温度そのものを識別するセンサー」や「水温を絶対に測らないケトル全般」は不可。台本の**一般的なタイプは**を保持する。
- バイメタルの形状（薄板・反転ディスク等）は参照できる動作機構と整合する一方式だけ採用し、途中で形が変わらない。赤熱して溶ける・液体化する表現は禁止。
- 家庭用電気機器の分解作業や露出した電源端子の撮影を促さない。写実映像で蓋を開けて沸騰を見せる等の危険な使い方を描かない。

根拠：
- バルミューダ公式FAQ（蒸気管と底部スイッチ）：https://faq.balmuda.com/answer/64707f21824840db046b3142/
- カインズ公式FAQ（蒸気がバイメタルサーモスタットに当たりOFF）：https://customer.cainz.com/support/faq/0000000058/0000000116/000017517
- ティファール公式FAQ（沸騰検知用バイメタル）：https://www.t-fal.co.jp/consumer-services/faq-product/?category-code=kettle-standard
- 名古屋市消費生活センター調査（バイメタル跳躍動作・スイッチ）：https://www.seikatsu.city.nagoya.jp/files/anzen/file/ketol.pdf
