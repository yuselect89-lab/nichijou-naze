## 制作・コスト・検証
- **制作順C04/C05→C06/C07→C01/C02/C03/C08**。科学的核心の2連続動作を先に実画確認し、失敗したものを量産しない。
- 2マスター（`CHOCO_MACRO_MASTER`と`CHOCO_PROCESS_MASTER`）を再利用。**8カットを8回別々のAI動画として生成しない**。油脂の結晶変化と水滴→砂糖溶解→蒸発→再結晶を、同じチョコ片の2つの**別の説明例**として動かす。
- **C05→C06の切替**は「もう一つの原因」等の短い語句を入れ、初期状態を明確にリセット。C08も実物の白い部分から原因を特定しない。「絶対カビではない」「安全に食べられる」などの断定は禁止。
- 白背景の小さな玩具・意味のない粒子・静止画ズーム連打・原理と異なる高価なAI動画は不合格。実物の質感と、大きく理解できる奥行きのある動作模型を優先。必要な動きだけ実生成・レンダーする。
- 素材制作開始時に既定のLOCK/SHA、`node tools/verify-production.mjs`、`npm run preflight`、素材ライブラリsearch/strict preflight/checkを実行。既存PASS素材はSHAで再利用し、失敗した部位と依存CUTだけ修正。生成回数・失敗理由・有料サービス利用を短く記録。無制限リトライ禁止。
- 1080×1920/9:16、無音。編集可能な背景・動作・文字・キャラのレイヤーを残す。既存`NNZ_CHAR_FEMALE_01`、文字4原則、360px・Shorts UI安全域。正式黄色帯・進行バー・字幕・VO・BGM/SEは素材に焼き込まず、Workで一度だけ合成。台本・承認済み音声は変更禁止。音声再送要求禁止。**音声実尺未測定のため、仮30秒に等分しない**。
- G2実画QC：C04/C05の部分融解と再結晶、C05/C06の新例への切替、C06/C07の水滴・砂糖の変化、C01/C08の同一性を実動画で確認。
