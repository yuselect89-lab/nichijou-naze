## 制作順・コスト制御
**C06 → C07 → C04/C05 → C01/C02/C03/C08**。最初に**同一VENT_HOLE**で「金型外へ空気排出→同じ穴にゴム侵入→加硫→離型→ヒゲ残存」が科学的に成立し、動画で理解できるか実際に確認する。空気とゴムを逆方向に描かず、金型外側に空気が出ることを示す。C07の各動作が認識できる秒数を実VOとの編集で確保。未実測段階で仮尺固定せず、ユーザーへ音声ファイルを求めない。
- **`MOLD_VENT_CUTAWAY`**をC04〜C07で再利用。カットごとに金型を再生成しない。**`TIRE_MACRO_MASTER`**をC01〜C03/C08で再利用。C01とC08は同じタイヤ・同じヒゲ。
- 高額なAI動画の生成は本当に必要な動作に限定。金型の空気の流れとゴムの変形は編集可能な連続模型で制御。必要以上の工場設備3Dを追加しない。無意味な粒子・白背景の小模型・静止画像のズーム連打は不合格。
- 素材台帳`library.mjs`の検索・事前照合、`verify-production.mjs`・`npm run preflight`等の既定検証を**実行**。PASS済みで未変更の素材はSHAで確認し再使用。失敗箇所と影響範囲だけを直し、無制限リトライ／勝手な高額モデル変更を禁止。使った生成回数と失敗理由は短いログに残す。
