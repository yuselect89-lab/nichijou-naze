## 0. 制作開始時の実体・仕様確認（必須）

- 最新のリポジトリと作業ツリーを確認。未コミットの他者作業、ユーザー承認済みの動画、旧EP、既存共通素材を破壊・上書きしない。
- `npm run preflight` を実行して、正式黄色帯の原本・SHA256一致を確認。**失敗時は制作を停止し、何を照合できなかったかを報告。似たものを作って代用しない。**
- `node tools/library.mjs doctor` を実行。必要依存が欠けたら内容を報告する。
- `node tools/library.mjs search '指 皮膚 血管 断面'`、`search '水 湯 指先'`、`search '考える'`、`search '拡大'`、`search 'ラベル'` などを実行し、既存素材とプレビュー、版、権利、依存関係、実ファイルを確認する。検索で見つかったら `resolve` でバージョン・存在・ハッシュ・QCを検証する。
- 使用できそうな共通資産の**カタログ掲載候補**（実際の検索・resolve結果が優先）：`NNZ_CHAR_FEMALE_01@v03_expressions`、`NNZ_CHAR_FEMALE_01@v02_highres`、`NNZ_LAYOUT_FOOTAGE_01@1.1.0`、`NNZ_LAYOUT_FOCUS_01@1.1.0`、`NNZ_TMP_CROSSSECTION_01@1.1.0`、`NNZ_TMP_ZOOM_01@1.0.1`、`NNZ_TMP_LABEL_01@1.1.0`、`NNZ_MOTION_BASIC_01@1.1.0`。**候補を利用可能と決めつけず、現行台帳と実体を先に照合。**
- `episodes/EP006/requirements.json` に、再利用できる素材を実ID・版付きで記録し、`node tools/library.mjs preflight episodes/EP006/requirements.json episodes/EP006/library_preflight.json --strict` を実行する。厳密検査がエラーを出した場合、結果を読んで reuse / adapt / create / blocked を仕分ける。**blockedは勝手に再生成しない。** create の必要性を台帳検索で確かめ、EP専用の新規素材として安全に作る。新作は初めから「既存素材として検査PASS」と偽装しない。
- 不足素材の報告に、ID・版・出典・権利・再利用／新規判定・プレビュー有無を含める。外部有料画像生成API・自動大量再生成は実行しない。実写が必要な場合は出典と使用条件を検証し、不明なら独自SVG・実写風CGなど独立制作案を優先する。

## 1. 素材設計（CUT01〜07）

**CUT01：お風呂の指先（Question）**
湯船に指を入れる動作と、シワがある指先へ変わる結果を理解させる。清潔で分かりやすい画面。黄色い正式帯を素材に焼き込まない。問い全文の巨大テロップは作らず、必要なら短い補助テキスト `シワシワ!?` を別レイヤーとして渡す。時間経過の表現は「水につけた直後すぐにシワになる」と誤解させない。

**CUT02：ふやけたから？（Reaction）**
指先・水滴と、高解像度の承認済み女の子の考える／疑問の表情を組み合わせる。短文は `水を吸ったから？`。吸水がそのままシワの原因と確定する誤った図を作らない。

**CUT03：仕組みへの誘導（Reveal）**
女の子が指先の内部に注目を促す。必要なら共通ズーム・フォーカス素材を再利用。次の科学図解に入る前に女の子を退かせる。

**CUT04〜06：最重要・一本の連続指先断面アニメーション（Focus）**
***3つの別画像を切り替えるのではなく、ひとつの継続するSVG/Remotionタイムラインとして制作してください。*** プレビューではカット対応点を記録するだけで、CUT境界で被写体を飛ばさない。

- CUT04対応パート：指腹の側面断面。輪郭・皮膚・指腹組織・小血管は別レイヤー。自律神経の働きが関わり、小血管が**細くなる**。詳細な神経の伝達経路は捏造しない。
- CUT05対応パート：同じ位置・倍率・向きのまま、血管内の血液量が減り、指腹組織の張り／体積感が**少し**減る。体積の変化を空洞・巨大な全体縮小として描かない。
- CUT06対応パート：同一図のまま皮膚の一部が連続的に内向きへ変形し、**浅い複数の谷が折り目として生まれる**。形成後の状態を短く保持して、視聴者が理解する余裕を作る。
- ***CUT04→05→06を通じ、表皮の下層と内部組織は常時ぴったり密着***。皮膚が剥がれる、浮く、水ぶくれになる、袋に空気が入る、パカッと分離する描写はすべて不合格。
- **左右分割・二画面before/after比較・途中で同じ断面に切り替える演出は禁止。** カメラ固定、構図固定、縮尺固定。
- 最終的なシワが360px幅でも見える程度に線を太く、造形を簡潔にする。医療用実寸比をうたわず、科学的理解を助ける模式図として扱う。根拠のない収縮率や圧力数値は表示しない。
- 見た目が水滴の膨張でシワができる誤解になるならその動きをやめる。神経の中へ水が流れる描写はしない。

**CUT07：実物の指先へ戻ってPayoff**
CUT06の浅い谷と実物の指先のシワが一致すると認識できるよう、同じ向きのアップでつなぐ。女の子を解説者として表情の読める大きさで表示（字幕・指先を隠さない）。短文は `中が少ししぼむ → 皮膚に折り目` 程度。確定結論を勝手に `体が起こした反応` へ戻さない。

## 2. 画面・音声・ブランドの保護

- 制作対象は**EP006の素材**のみ。完成編集はChatGPT Work側。
- 1080×1920 / 30fpsの縦動画想定。透明レイヤーを保持するため、可能な限りSVG/React/Remotionソースを納品し、H.264に透明合成を頼らない。背景・キャラ・図解・ラベルを独立させる。
- 女の子は説明者：CUT02/03/07は大きな上半身・表情重視。CUT04〜06は原則非表示。小さい全身を隅で歩かせるだけの演出にはしない。
- 公式帯の唯一の原本：`public/series/approved/opening_banner.png`、`production-lock.json`。**帯自体は素材に合成しない**。新しい黄色帯や `秒で解決!!` の再現は禁止。
- 全編進行バー・VO・字幕・BGM・SEも素材に焼き込まない。合成指示にのみ記載。字幕は `、` を除去して `。` を維持する本編既定処理を前提とする。
- 確定台本V4・話し方・解説順・文章は変更禁止。音声ファイル未確認なら仮のBGMや仮VOを作って本番尺とみなさない。**VO実尺未確定**なのでカット秒数は編集可能な相対タイムラインで設計する。
- 360px縮小時の図解視認性、YouTube Shorts右側のUI領域、下部字幕、黄色帯と被写体・文字・女の子の干渉を確認する。左右余白の無意味な偏りも避ける。

## 3. 制作・セルフQCの順番

1. **事前インベントリ**：再利用候補・使えるファイル・足りない素材を特定し、まず報告ファイルに記録。
2. **素材の制作**：不足したEP固有素材だけを制作する。CUT04〜06は一つのソース・一つの変形アニメーションを優先。
3. **素材プレビュー**：CUT01〜07の静止プレビュー／360px幅の縮小検査画像と、CUT04→06連続アニメーションの実レンダーを制作。プレビューには字幕・正式帯・音声を焼き込まない。
4. **科学的セルフQC**：CUT04開始／血管収縮中／内部収縮中／シワ完成の少なくとも4段階を抽出し、表皮と内部組織に隙間がないことを確認。CUT04〜06に画面分割が一瞬も出現しないことを検査。
5. **登録処理**：新素材は一旦EP固有の実ファイル＋manifestとして保存し、QCを記録。汎用化に適したもののみ、ユーザー承認済み運用（候補→実レンダー/QC→IDと版を付けて正式登録）に従い共通台帳へ**追記**。既存ID・版上書き禁止。テンプレや一般素材を実際には検査していないのにPASS扱いにしない。
6. **引渡し**：作業結果を `episodes/EP006/` 内に揃える。Git commit、パス・SHA256・バージョン・依存・再生手順・権利・使用条件・不合格/未制作リスト・QC結果を含める。

## 4. 必須納品物

- `episodes/EP006/assets/`：CUTごとの実ファイル（EP内の既存同名ファイルがあれば別バージョン名で保存）。

- `episodes/EP006/manifest.json`：各カットのsource / start-end / layer / reference / asset_id / version / rights / sha256。未確定尺は provisional と書き、本番尺を偽装しない。
- `episodes/EP006/LIBRARY_DECISIONS.md`：検索・resolve・preflightの結果、reuse/adapt/create/blockedの判断・ID/版・実体・QC参照・依存・権利。
- `episodes/EP006/ASSET_QC.md`：個別素材の実レンダー結果、視認性・密着・連続性・字幕/帯の安全域、未解決の事実。

## 5. 受入条件（1つでも満たせなければPASS報告禁止）

- 台本V4に一文字の無断修正もない。
- 本番ブランドの正式帯原本SHA256一致が `npm run preflight` で確認できる。
- CUT04〜06は一枚の断面図が連続的に変形しており、左右比較・分割・カメラ変更・別絵への不連続ジャンプがない。
- 表皮と内部組織の剥離・空洞が一切ない。模式図として機序が正しく、シワの谷が視認できる。
- 女性キャラのサイズ・表情が説明役として読める。科学図解中に邪魔をしない。
- 実在・ハッシュ・QCを確認した共通素材のみ使う。存在を確認せず最新版の名前だけ採用しない。
- 完成済みEP・共通素材の正本・既存ロゴ・本番投稿ファイルを変更していない。
- 未完成・未検証があれば、そのまま**未完了**として正確に報告。素材を捏造・すり替え・自動再生成して埋めない。

## 6. 制作結果の報告形式

- ① 素材制作：完了／部分完了／停止
- ② 再利用したIDとバージョン、参照した実体と検証結果
- ③ 新規制作したファイルのパス・SHA256
- ④ CUT04〜06の連続性・表皮密着のQC結果、プレビューへのリンク/パス
- ⑤ 7カットの作業状況と依存／権利／尺の未確定事項
- ⑥ ChatGPT Workへ渡す次工程の入口と、実行済み検証コマンド
- ⑦ 実際のcommit SHA（pushした場合）

**エンドゴール：** 見るだけで「指の内部がわずかにしぼむと、表面に浅い折り目ができる」と理解できるEP006素材。とくにCUT04〜06を曖昧な静止画切替で済ませないこと。
