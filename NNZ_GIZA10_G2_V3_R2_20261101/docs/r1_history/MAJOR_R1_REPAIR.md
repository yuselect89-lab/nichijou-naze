# MAJOR受入指摘への修正 — R1

対象：C01/C03の人物が頭部付近で切れ上半身の仕草が欠ける、C06の髪が右安全枠で切れる、の3指摘。
旧版の受入判定はMAJOR。デコード・ハッシュが正しくても実画の品質合格ではなかった。旧版の内部確認で人物切れを見落とした。
今回確認した指摘はチャット本文。GIZA10_G2_V3_WORK_REVIEW_20261031.zipという名前の記載はあるが、このターンではZIP実体は取得しておらず、その内部資料を読んだとは扱わない。

## 原因と実装修正
1. 人物を縮小した後に固定サイズで再切抜きしていた。C01/C03では腕・手まで削られ、頭部中心の素材になっていた。縮小後の切抜きを全廃し、髪と手を含む登録済み人物の上半身クロップ全体を、縦横比のまま縮小した。
2. 右安全枠の透明クリップで、枠外に出た髪を消していた。C06を左上へ移し、上半身と髪を含む全体を枠の内側へ配置した。
3. C04も同じ固定切抜きを使っていたため、上半身全体を保持する方式へ統一した。

## 再発防止

- source/render_project.py：人物の比率変更、またはクリップ前の髪・手・体のはみ出しをエラーで停止。安全枠で人物を削って通すことを禁止。
- source/check_presenter_integrity.py：元の上半身全体の縮小画像との画素一致、登場中の全フレームのクリップ前境界、実動画の人物アルファと全姿の一致を検査。
