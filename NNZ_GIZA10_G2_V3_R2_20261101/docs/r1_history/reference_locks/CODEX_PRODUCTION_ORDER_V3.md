# Codex実行指示｜ギザ10 G2 V3 写真＋意味のあるモーション素材制作

先に `G2_V3_VISUAL_DESIGN_PROPOSAL.md`、`RIGHTS_AND_FEASIBILITY.md` と同梱キーフレーム12枚を読み、元受領ZIP `nichijou-naze-delivery-giza10-work-assets-20261031.zip`、専用リポジトリの `AGENTS.md`／`production-lock.json`／関係LOCKを確認してください。**今あるV2を上書きせず、V3候補として実画QC素材を制作**してください。

## 作業分担と再利用
- **Codex：** 完全なリポジトリで `npm run preflight`／`npm test` → ライブラリ検索・preflight → 写真の個別ライセンス・実画検証 → **C01〜C06の写真・図解・台座・キャラが独立した無音映像素材と編集ソースを制作**。BGM・SE・ナレーション・字幕は合成しない。平面の硬貨写真を3D硬貨にしたふりをしない。
- **Gemini：** 12枚の代表フレームとC01～C03／C04～C06の無音動作実画をG2審査。意図したV2→V3変更を含めてQC。
- **Work：** G2通過後にユーザー確定ナレーションと字幕、正式黄色帯、単一進行バー、既存CTAを本編合成してG3。本件の年号音声齟齬が解決するまでは公開完成版にしない。

## アニメーション指定（見た目の動きではなく意味）
1. **C01**：ギザ10実物写真のフチを見せる小幅パンとガイド線。写真の元画素不足を人工的な溝生成で補わない。`question`の高解像度上半身は後半。冒頭で写真が使えないときはC01 HOLD。
2. **C02→C03**：同じ旧10円写真パネルと同じ台座を維持し、C03の「なんと最高額」で10円パネル自体が最上段へ上昇する。3D回転ではなく**写真パネルの位置移動**。C03最上段で「硬貨の最高額＝10円」を強調し、短い `reaction`。
3. **C04**：旧10円の台座を維持し、1955年の穴なし菊花50円の写真パネルが10円より高位へ入り、1957年の鳳凰100円がさらに上へ入る。**表裏写真が存在することを活用しつつ、実物と誤認させる側面回転は無し**。写真は元の片面画素数を超えない程度の表示。各台座の額面数字と西暦は写真から独立レイヤー。`process_intro`は初めだけ。
4. **C05**：10/50/100円はいずれもギザ付きという共通点を短いラベルと**「模式図」明示の縁のパターン**で示す。1959年旧型→新型は別写真パネルの移動として示し、旧コインのギザが溶解・消去される変身は禁止。
5. **C06**：旧10円／新10円の実物写真を同じ写真パネル直径で比較。縁については別パネルの模式図「ギザあり／ギザなし」を同倍率で比較。実物写真・模式図・字幕を混同しない。C03の頂点の光を短く回帰し `payoff` を表示。

## 既存共通素材の扱い
- 正式黄色帯SHA256 `e6b63c322c996f543930a027db8981c2388e88441656655822c34bb4e2e2fd37`。Codexの無音素材には焼き込まない。Workが一度だけ合成する。

- 編集用の各要素（写真、文字、図形、キャラ、背景、動き）は個別レイヤーで渡す。
- ユーザー確定音声を加工・再生成・外部アップロードしない。音声提出を要求しない。BGM/SEは追加しない。
