# ギザ10 G2 V3：制作可能性・写真権利の実務判定（2026-10-31）

## 結論
- **C04の3Dモデル精密再現**：今回の写真素材では根拠不足。**採用しない**。
- **C04の2D実物写真と階層モーション**：制作可能。採用する。旧50円・旧100円の写真を**両面合計の横幅960／800px全体から拡大することはせず**、各貨幣の元画素を考慮して配置する。表面の図柄は独立したベクターアイコンで模倣せず、実物写真のままにする。
- **C01のマクロギザ可読性**：S29の1200x900転送コピーがあるが、実際の縁の可読性が未確定。実画ゲートを必須にする。比較写真の元3840x2160はGoogle Slidesを経由すると2048x1152に縮小されたため、これを「元4K」と称しない。
- **C05/06の側面**：新旧写真だけでは側面の実証ができない。模式図で明示し、側面写真の実証を偽らない。
- **音声**：ユーザー提供の30.433秒原本を維持。提示文章の「1950」と公式史実「1951」が不整合。映像化とは並行して別途解消する必要あり。ロック済音声は無断修正禁止。

1. C01写真で360px動画にしたときギザの明暗が区別できる。元画素が足りなければ別写真を探索し、不合格のまま利用しない。
