## 依頼

最初に `INVESTIGATION.md` を読む。今回は「頂点」という空台座の装飾と、ギザの見えない正面写真比較を廃止し、額面の移り変わりと実際の縁の違いが伝わる分離素材を作る。旧版の人物切れ素材・不合格3Dは混在させない。

## 演出を変更する理由

「頂点」は額面の最高額を比喩で呼んでいるだけで、現行の空台座は何の説明にもなっていない。正面写真二枚の模様はほぼ同じなので、これを大きく並べても縁の違いは伝わらない。どちらも表示位置だけの手直しで完了としない。

時間は現行本編の参考値。最終同期は既存edit.jsonの確定音声に対して行い、レイヤー全てに同じ時間マップを使う。素材側で音声の速度を変えない。

## M03：今回確認した実写候補

`references/COMMONS_COMPARISON_ORIGINAL.jpg`

- 原本：3840×2160、1,142,673 bytes。今回公開配信原本を取得して実画確認。従来の2048×1152転送コピーとは別物。
- SHA256：37b031e4b8b13e147aeda6625e620913024dc2b433f4805669da44a6244ac0b7
- 作者：Renault R.S.01、CC BY-SA 4.0。出典・ライセンスは `RIGHTS.md`。
- 左の手前側にギザが写り、右の手前側は滑らかな縁が写る。原本全景のまま縮小すると硬貨が小さ過ぎるため、余白を大きく切り詰める。
- 題名は「昭和26年」だが、実画の年銘は左が昭和二十九年、右が平成元年と読める。ページの1954年・1989年カテゴリとも整合する。**1951年と1959年の現物比較写真と呼ばない。** 精密な個体年銘の紹介は今回不要で、型式比較として使う。
- 同じ写真に二枚が写ることは比較条件の利点。ただし摩耗・影・色の違いをギザの差と誤認させない。右の面と側面の境界線を溝と呼ばない。

切出しは硬貨前縁の円弧とその上の面の一部を残す。溝だけの細い帯を切り離して正体が分からなくしない。背景を消す場合も縁を削らず、処理は別マスクに保存する。縦横比を変えて厚みを増やさない。AI補完、溝の描き足し、超解像で溝を創作、リライティング、写真の立体回転は禁止。

**採用手順は固定する。** 最初に実写の旧・新拡大を同じ程度の倍率で並べ、1080pxと360pxの動画で判別を確認。360pxで溝を複数本区別できない／右の平滑縁を面と区別できない場合、実写は小さな確認写真として残し、M04の大きな接続模式図を主図に切り替えて制作を続ける。原本が4Kであるだけでは採用合格にしない。現行の小さな棒状図へ戻さない。

M04は横長の平面側面図を主図にする。1080版の1段は概ね幅600〜720px・高さ120〜160px、360版で幅200〜240px・高さ40〜53pxを目安とする。ギザ線と隙間は360版で各2px程度以上を確保し、実物の溝数や寸法の精密再現とは主張しない。上下で形・縮尺をそろえ、線の有無だけで違いが分かるようにする。薄い色の差や細い1px線だけに依存しない。実物写真の該当縁と引出線で接続する。硬貨とは無関係に見える独立した棒にはしない。

## レイヤー・納品形式

- R1と同じ1080×1920、24fps、透明付きMOV（qtrle/ARGB）の写真・図解・ラベル・人物の4系統を各カットで納品する。編集可能なSVG、JSON、コード、フォント来歴、使用原本、マスクも添付。人物を含め全レイヤーの時間軸と総フレーム数を一致させる。
- M03の写真とM04の模式図、文字は独立させる。写真へ描き込んだ溝・写真に焼き込んだ文字にしない。
- 無音の連続プレビューを1080版・360版で出す。C02→C03→C04の最高額の移動と、C05→C06の縁の理解を途切れず確認できること。静止画だけで納品しない。
- 素材プレビューへ正式帯・字幕・進行バー・CTAを焼き込まない。本編側で各一度だけ合成する。字幕予定域には確認用ガイドを別レイヤーで表示できるようにする。
- CHANGELOG、採用／不採用素材一覧、権利、原本ハッシュ、切出し座標、検査動画と根拠フレームを付ける。

## 実画での受入条件

1. C02〜C04を無音で見ても「10円が最高額だった→50円→100円に移った」と画面の対象を指せる。空の頂点・空の順位台座は存在しない。
2. C05は10・50・100の3枚ともギザ付きという共通性、1959年の10円写真は別素材という変化が分かる。
3. C06は360pxを通常サイズで再生し、ラベルを読む前にもギザの有無を指し分けられる。実写が弱いなら指定の大きな模式図を主図へ切り替える。文字だけ「ギザあり／なし」でも絵で分からなければ不合格。
4. 新旧の面写真がほぼ同じことを不必要な違いとして演出しない。実写縁と模式図を偽らない。
5. 全6カットの登場途中・完全登場・終了側で人物、写真、ラベル、引出線が衝突しない。C01顎の手・反対腕、C03胸元の両手、C04指差し、C06髪と挙手を保持。
6. 現行本編の字幕予定域X140〜938/Y1510〜1750、右UI想定域X940〜1080、進行バーX96〜930/Y78〜92を避ける。正式帯は原本・制作ロックの実際の占有域も含めて確認する。これらを唯一の安全域の定義としてR1規定を縮小しない。
7. 発光や引出線を年号・金額に重ねない。動く全フレームで確認し、途中だけ読めなくなる演出も直す。
8. 完全な専用リポジトリでnpm run preflightとnpm testを実施し、終了コード・結果を記録する。素材だけのR1 ZIPに検査コードがない場合、完全な既存リポジトリへR1を正しく導入する。架空の成功ログを作らない。
9. デコード・ハッシュ・内部レイアウト検査の成功と、説明内容の受入を別に記録する。今回の新規実画審査、外部G2、音声不整合の状態をそれぞれ正しく記載する。

## 本編側へ引き継ぐ制約

既存音声は無加工で保管。字幕は読点「、」だけを除き、句点「。」を残す。音声に合わせ全レイヤーを共通の時間マップで同期する。BGM・SEなし。審査用MP4を本編ソースの代わりにしない。正式黄色帯は承認済み原本のハッシュを照合して一度だけ合成する。現行プロジェクトで既存CTA原本・文言が未特定の問題は未解決として継承し、別文言を捏造しない。

候補動画の編集・書出しは進められるが、約9秒台の1950年という音声の史実誤りは字幕のみで解決しない。公開時に音声と史実を一致させる対応には別途明示的な許可が必要。素材修正の完了と音声修正の完了を混同しない。
