## 編集レイヤーと順序
1080×1920 / 24fps。まずassets/background.pngを置き、その上に各C01〜C06のMOVを下記順で重ねる。
1. diagram_motion_RGBA.mov：台座・縁模式図だけ。
2. photos_motion_RGBA.mov：実物写真だけ。
3. labels_motion_RGBA.mov：説明用の短いラベルだけ。ナレーション字幕ではない。
4. presenter_motion_RGBA.mov：人物だけ。C02/C05には人物なし。

C01だけは写真→図解→ラベル→人物の順。縁を指す独立ガイドを写真の上に置く。他カットの台座の光は写真の下へ置き、写真の色・照明を変えない。正確な順序は各JSONのlayer_order。

全MOVはQuickTime Animation/qtrle、ARGBの可逆透過、無音。アルファはstraight/unmattedとして扱う。黒い不透明背景の動画ではない。背景と人物・ラベルを二重に貼らない。

previews_1080/ と previews_360/ のMP4はG2実画確認用の合成プレビュー。本編素材として貼り付けず、上記分離レイヤーを使う。PREVIEW_AはC01〜C03、PREVIEW_BはC04〜C06の連続確認用。

## 編集可能なソース
scenes/C01.json〜C06.jsonが各要素の相対パス・位置・サイズ・不透明度・秒単位キーフレーム。x/yは左上、w/hは表示画素数。補間はsmoothstep。groupはphotos/diagram/labels/presenter。元PNGと編集可能な文字SVG、書体をassets/に同梱。
scenes/Cxx.svgは各層を独立グループにした自己完結型SMILアニメーション。ブラウザで単独表示できる。OPEN_PROJECT.htmlから確認可能。SVGに写真を埋め込んでいるが、写真を立体硬貨として回転させる処理はない。

Python 3 + Pillowとffmpegがあれば、展開先に依存せず `python source/render_project.py --cut C04` でそのカットの分離MOVと1080プレビューを書き出せる。`--cut`省略で全6カット。写真・図形の再作成は `python source/build_assets.py`。現在のJSON構図は上書きしない。`python source/validate_delivery.py`で縮小・実動画フレーム抽出・連結・全デコードを再実行。フルリポジトリのpreflight/testは別途必要。

## 台本とカット対応
C01「昔の10円玉。なぜフチがギザギザ？」：実写真を原寸以下で小幅移動。ガイドは写っている右手前の縁へ追従。後半に写真を右へ縮小移動し、左のquestionと干渉しない位置にする。
C02「当時は最高額の硬貨にギザを付ける慣習がありました。」：同じ旧10円の写真パネルと中央台座。頂点だけを予告し、10円はまだ登頂しない。
C03「1951年に製造が始まった10円玉が、なんと最高額！」：C02と同じ写真が台座最上段へ上昇。到達後にreaction。主ラベルは硬貨の最高額＝10円。1951年に現行100円等を混入させていない。
C04「ところが50円、100円も登場。どちらもギザ付き。」：旧10円を下段へ、1955穴なし菊花50円、1957鳳凰100円を順番に上段へ。3枚の写真直径は282/300/271pxで実物径23.5/25.0/22.6mmの比率を維持。指差し役は上部の別領域から案内し、早めに退場。50円は上方の空き領域を通ってから台座へ収まり、10円の写真を横切らない。登場時の額面ラベルは写真の上で追従し、到達後に台座上のラベルへ切り替える。写真への重なりを避けるため補助矢印を省き、台座と写真の段階移動を主演出にした。
C05「見分けにくくなったことなどから、1959年に10円のギザは廃止されました。」：まず3枚と明示的な縁模式図で共通点。旧10円を残し、1959年の別写真を横から導入。変身・溶解なし。終盤は新旧上下の比較へ接続。50円/100円の写真が消えてから旧10円を拡大し、1959年写真が収まってから下段模式図と比較ラベルを出す。
C06「あのギザは、10円玉が硬貨の頂点だった時代の名残なんです。」：新旧を同じ340pxの写真パネルで上下比較。写真と独立した同じ大きさの模式図。C03の頂点の光を回収してpayoff。写真の照明は元資料のままで、実測同条件の側面写真比較と称さない。

## 尺・本編合成
尺はV3設計の目安をフレームに丸めた編集用ハンドル。計約30.625秒だが、確定音声を測定・同期した値ではない。WorkでG2通過後、既存確定音声の発話位置に合わせて各レイヤーを同じ時間マップでリタイミングする。音声を変えずに映像のホールド等を調整する。
正式黄色帯、音声、ナレーション字幕、単一進行バー、指定CTAはこの素材に焼き込んでいない。Work本編でそれぞれ一度だけ。字幕表示では読点「、」だけを除去し句点「。」を保持する。帯は承認済み原本SHA256を確認し、上書き・近似画像への差替えは禁止。
字幕予定領域Y1510〜1790、右UI予約X940〜1080を空けた。全透過レイヤーはX940以右を共通の透明安全枠でクリップする。横から入る写真がUIの上を横切らないようにした。自己完結SVGにも同じクリップを適用する。C01の正式帯は既存LOCKの位置で描くと不透明部がおよそY332〜580に来るので、主見出しはY600以降とした。安全域は最終アプリの実UIと本編合成でも再確認。
