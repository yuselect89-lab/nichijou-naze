## 2. 構図と動作（ナレーションを基準・時刻は波形による暫定値）

**基本画面**：1080×1920。全景を中央基準で組み、発話と主体の動きを合わせる。主写真／図解は原則Y=270～1400に置き、字幕Y=1510～1790、公式帯と進行バー、YouTube右UIの安全域は本編で別レイヤー照合する。キー画像の下の説明ボックスは**審査用注釈**であり本番素材には含めない。

## 3. 文字の4原則と安全域

全カットで主役は写真・歴史上の位置関係。太字は「10円／50円／100円」「最高額」「ギザあり／ギザなし」だけ。補助年号は細いゴシック・低コントラストで区別。字形の正しい Noto Sans CJK JP を使用。青銅／ニッケル／銀貨の質感差は**実物写真**由来とし、コイン写真へ無根拠な金属光沢を加えない。共通黄色帯、進行バー、CTA、字幕は**Workの本編で1回だけ**合成する。

- `primary_text`: C01「ギザギザ？」、C02「最高額の硬貨」、C03「最高額＝10円」、C04「50円」→「100円」、C05「1959年」、C06「ギザあり／ギザなし」。
- `secondary_text`: C01なし、C02「当時」、C03「1951年」、C04「1955／1957」、C05「模式図」、C06「模式図・名残」。
- `size_hierarchy`: C01は縁→短問、C02は台座頂点→概念、C03は上昇する旧10円→発見、C04は階層の移り変わり→額面、C05は新旧10円の交代→模式図、C06は新旧の比較→回収。
- `weight_strategy`: 額面・主発見を実在Bold、補助年号Regular。疑似太字は禁止。
- `luminance_strategy`: 展示台の最上段だけ視線の光を使う。意味のないグロー・画面全体の明滅を禁止。
- `typeface_reason`: 数字と短い説明を0.5秒でも判別できる日本語ゴシック。明朝は今回不要。
