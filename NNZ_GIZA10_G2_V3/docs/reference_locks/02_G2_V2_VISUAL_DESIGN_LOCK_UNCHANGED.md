## 3｜カット別・画面構図・連続動作

### C01 — 問い／実物から入る（発話1）
**主題：本物のギザ十の“フチ”が最初に見える。**

- 画面開始フレームは**実際の硬貨を撮影した、利用条件を確認済みの写真**。実写ではないレンダリングを冒頭の実物として提示しない。
- フレームの中心に斜め上から見た硬貨。側面のギザが一列の明暗の凹凸として観察できる。硬貨全体を小さく置いて、単に「10円」だけを読ませない。
- 実写の可動表現は**緩いカメラ移動／光量差の演出**まで。単一写真のコインを強引に3D回転、生成塗り足し、溝の描き足しをしてはいけない。ギザの幅に対して必要以上に拡大しない。
- 「なぜフチがギザギザ？」に対し、縁を追う短いガイドの動き。問い全文を大テロップにしない。
- 女性案内役 `question`：後半に上半身で視線をフチへ誘導。フチ上に指や顔を重ねない。写真の可読性を下げるなら登場を後段へ移す。
- **C01の素材決定ゲート：** 既存Monaneko 1024×768をマクロ主素材として採用しない。候補① Wikimedia 3840×2160「ギザ10『昭和26年』と現在の10円硬貨.jpg」（Renault R.S.01／CC BY-SA 4.0）、候補②「S29-10yen.jpg」（ぽん56／CC BY-SA 3.0、1200×900）、候補③新規に商用利用許諾の取れる実物の縁マクロ。**①②の実際のギザ可読性は未確認なので、候補であって採用済みではない。** 有効な溝の見えを原寸確認し、縦動画へのトリミング＋360px試写で初見でも判別できるものだけ採用。全候補不合格なら本カットはHOLD（低画質で強行しない）。

### C02 — 最高額の慣習／導入（発話2）
**主題：ギザ＝当時の最高額面の慣習。10円という事実は隠さず、最高額との関係をまだ完成させない。**

- C01の実物ギザの向き・場所・画面中の相対位置を保持しながら、検証を通した**ギザ付き10円3Dモデル**へ映像内の明確なマッチカット。**切替後の立体表現は実写と偽らない**。
- 3D硬貨を側面が見える角度から追い、画面奥に奥行きのある「当時の硬貨の序列」の展示台がせり上がる。トップに光が差す。コインは10円だと分かって構わないが、**1951年に最高額だった**という結論の視覚表現はまだ完成させない。
- 「最高額の硬貨」の短テロップを奥の頂点付近に結びつける。背景で大量の硬貨や紙幣を混ぜない。硬貨の最高額と金銭全体の最高額を混同させない。
- `focus_only`：案内役を出さない。視線は溝→頂点へ一方向に誘導。

### C03 — 主発見のリビール（発話3）
**主題：「10円＝1951年当時の最高額硬貨」という関係を、画像だけでも理解できるようにする。**

- C02から**同じ3D十円硬貨が切れ目なく側面→表面へ回転**。モデルを突然別画像に置換しない。
- 「1951年に製造が始まった」で小さく時代表示「1951年」。硬貨の面に10円が読める向きになる。
- 「なんと最高額！」の瞬間に、**その十円硬貨自体が展示の最上段へ滑る／台座が上昇する**。これは「10円を見せる」演出ではなく「10円が頂点だった」という意味の演出。俯瞰気味へカメラが移り、コインの頂点に結びつくテロップ **「1951年・硬貨の最高額＝10円」** を表示。時間軸・硬貨であること・価額を同一画角で結ぶ。
- **現行500円や100円を1951年の展示に混在させない。** 比較物を置く場合、当時の硬貨の実在仕様を検証できたものに限る。時代の誤解を避ける第一選択は、貨幣の追加ではなく**展示台の頂点位置で示す**方法。
- `reaction`：女性案内役はコインが最上段に立った後、驚きの表情で上半身登場。顔が読める位置とサイズ。コイン・「最高額＝10円」を隠さず、短く反応して退場。
- **必須試写：** ミュート・360px表示で視聴して「10円玉にギザ」だけでなく**「1951年には10円玉が最高額の硬貨」**まで伝わるか。刻印だけが目立つ場合は不合格。

### C04 — 50円／100円の登場（発話4）
**主題：10円がトップでなくなり、別のギザ付き硬貨が増えた。**

- C03の台座・十円コインを同じ画面内に残す。横から**1955年の50円ニッケル貨（穴なし）**が入り、さらに別方向から**1957年の100円銀貨（鳳凰）**が登場する。
- 50円登場時に10円の「最高位」より上の位置へ50円が移る。100円登場時に100円がさらに上段へ入り、**10円→50円→100円と最高額面の位置が移ったこと**を位置変化で見せる。貨幣そのものの額面を変化させない。年は小さく `1955` / `1957` と従属情報として出してよい。
- 「どちらもギザ付き」で3枚が同じカメラに向かって**傾き、ギザのある縁を見せる**。3枚の大きさを一律にしない。実際の直径は旧10円23.5mm、旧50円25.0mm、旧100円22.6mm。<https://www.mof.go.jp/policy/currency/coin/general_coin/list.htm>
- 50円／100円の当時の図柄（菊花、鳳凰）・素材差を確認。**現行の穴付き50円や桜100円を差し込まない**。
- `process_intro`：女性案内役は50円の登場を短く案内し、3枚の縁の実演前に退場。コインへの指差しがなければ無目的な表示をしない。

### C05 — なぜギザが消えたか（発話5）
**主題：ギザの増加→1959年の十円の仕様変更。溶けて消えたような虚偽表現にしない。**

- 3枚のコインを縁が同時に見える角度に揃える。光がそれぞれのギザを順に横切り、**どれもギザ付きという共通点**を見せる。ただし側面だけの映像を長く続けず、どの硬貨かが分かる額面ラベル／コインの一部を残す。
- 「1959年に」の発話で新しい縁仕様の**別モデル**を導入する。旧十円は奥へスライドし、その横から1959年仕様の平滑縁十円が同じ向きで入る。**旧十円を削る／ギザが連続的に溶ける／同一の古銭が新品に変身する演出は禁止**。
- 新旧の表面の図柄・直径・色味は同一系列の十円貨として自然に。異なるのは主に縁と刻印年など年代に依存する部分。写真「10yen-S34.jpg」は**正面デザインの参照のみ**であり、滑らかな側面の実画証拠にはしない。
- `focus_only`：案内役非表示。

### C06 — 最終比較と余韻（発話6）
**主題：ギザは“当時の最高額”の名残だと見て分かる。**

- 同じ直径・同じ遠近法・同じ照明方向・同じ角度の二枚の十円モデルを、**上下に大きく配置**（上：1951年仕様・ギザあり／下：1959年仕様・ギザなし）。縦画面で小さい硬貨2枚を横並びにして側面の線が潰れる構図を避ける。
- 双方が**同時に少し傾き、縁が最もよく見える一瞬で揃って停止**。横移動する細いハイライトで「上：細かな凹凸／下：連続した平滑面」を読ませる。二枚の片方だけ拡大率やコントラストを変えて差を捏造しない。
- 各コインの近くに短いラベル「ギザあり」「ギザなし」。音声終盤「硬貨の頂点だった時代」で、上の旧十円にC03のトップ台座の光・輪郭を**短く回帰**。余韻で主発見を回収。最終フレームは旧ギザと現行型の差が残る。
- `payoff`：案内役がラベル・側面を隠さない位置に上半身で登場し、古い十円を見て短く頷く。常時小さく歩かせない。
- **絶対に必要な証拠：** 旧10円と新10円の3Dモデルの側面を同条件でレンダリングした静止画と、両方が傾く動作プレビュー。実物のギザ／平滑の差が確認できるまでPASS不可。
