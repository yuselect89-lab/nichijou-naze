現時点で、Wikimediaの画像バイナリを本作業環境に取得して原寸切り出し／画質測定する工程が成立していない。そのため **C01の商用利用可能な実写マクロ素材が「画質も含めて確保済み」とは報告しない。**

## 画質QCでの受入条件

1. 公開された原本データを取得し、側面ギザの範囲の有効ピクセルを記録する。単なる原本全体の大きさは評価しない。
2. 1080×1920フレームの実際に使用する構図でレンダーする。横長原本を無条件に中央9:16トリミングしない。
3. 360×640実画で「ギザあり」と読めることを第三者QCに確認させる。ズーム時に元画素を極端に超えて引き伸ばさない。
4. 失敗なら別候補へ進み、それでも失敗ならC01 HOLD。販売写真や生成画像で穴埋めしない。
5. CC BY-SAの作品名・作者・URL・ライセンスURL・加工（クロップ／色調整／動き付け等）の有無をクレジット案に記載し、継承条件への対応を確認する。
