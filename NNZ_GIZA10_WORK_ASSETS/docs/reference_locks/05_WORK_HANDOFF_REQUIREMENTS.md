# Work引継ぎ要件

Codex納品物は、Workが次工程で1本の完成動画へ編集できる構成にする。

## 想定フォルダ
- `C01/` 〜 `C06/`
- `shared/`（共通ラベル、キャラ、比較パーツなど）
- `3d_models/`
- `stills_for_qc/`
- `docs/`

## 各カットに最低限必要なもの
- ベース静止素材または背景
- 動く要素（ある場合は無音動画 or 連番PNG）
- テキスト/ラベルの別レイヤー
- そのカット固有の注意点
