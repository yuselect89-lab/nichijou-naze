# ギザ10｜Codex素材制作 指示書（2026-10-31）

## 目的
「日常のなぜ？」ギザ10の**動画編集用素材**を制作する。
**完成動画は作らない。** Workが後で完成動画を編集する。

## 正本
- 映像設計正本: `02_G2_V2_VISUAL_DESIGN_LOCK.md`
- C01権利監査: `03_C01_RIGHTS_AUDIT.md`
- 3D外周形状の初期入力: `04_GEOMETRY_INPUT/`

## 今回Codexが作るもの
### C01〜C06用の素材
- 実写写真を用いるカットのベース素材
- 画像・図解・ラベル・比較ボード
- 3D硬貨素材（旧10円ギザあり、1959年10円ギザなし、1955年50円、1957年100円）
- 必要な無音アニメーション素材
- 編集可能なソース（Blender等）
- 分離レイヤー（背景、硬貨、ラベル、キャラ、比較要素など）
- Work向けの素材台帳・引継ぎ書

## 作ってはいけないもの
- 完成動画1本
- カットごとの完成版ショート動画
- 音声入り動画
- BGM/SE

## 守ること
- 台本・構成・カット順は変更禁止
- 音声には触れない
- C01は `03_C01_RIGHTS_AUDIT.md` の商用利用確認済み候補のみ検討対象
- `04_GEOMETRY_INPUT/` のGLB/OBJは**外周形状の初期入力**。図柄・刻印・ギザ本数/深さは必要に応じて修正・精密化する
- 納品は**素材一式**。Workが編集できる状態にする

## 必須納品
1. C01〜C06に対応した素材フォルダ
2. 無音アニメーション素材（必要分のみ）
3. 4種類の編集可能3Dモデル
4. 代表フレーム
5. 素材一覧（ファイル名、用途、権利、注意点）
6. Work向け引継ぎ書
7. ZIP一式

## 最低検査
- 6カットすべてに必要素材があるか
- 画像・動画・3Dのファイル破損がないか
- Workが編集できるようにレイヤーや透過が保たれているか
- 権利記録が素材一覧に書かれているか
